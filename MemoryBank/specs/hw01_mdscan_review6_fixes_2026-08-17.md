- from Alex - 1. я не совсем понимаю(  2.один поток работает без обвязки он должен работать быстрее чем один поток в потоковой обвязке но у нас их 5 потоков; 3. ты про какой из 3 токов говоришь кто самый медленный и почему? 4. может увеличить кол-во потоков
- ✅ Кодо — ответ числами (набор B, 500 файлов, 1025 ссылок; 5 прогонов, медиана):

  | режим | 1 поток | 2 | 5 | 10 |
  |---|---|---|---|---|
  | **без HTTP** (работа = разбор Markdown = чистый Python) | 0.61 с | 0.60 | 0.65 | 0.66 |
  | **с HTTP** (600 запросов, сервер отвечает 30 мс) | 27.2 с | — | **5.05 с** (×5.4) | **2.57 с** (×10.6) |

  1. «Один поток без обвязки быстрее одного потока в обвязке» — да: последовательный цикл read+extract+check = 0.34 с +
     обход 0.12 = 0.46 с; тот же объём через конвейер (очереди, сентинелы, 1 воркер) = 0.59 с → обвязка стоит ≈0.13 с (22 %).
  2. Три вида потоков: **discover** (обход, 0.12 с, один репозиторий → один поток занят), **parse** (чтение + разбор +
     проверка, 0.34 с — самый медленный), **collector** (складывает результаты, ~0). Самый медленный — parse, и его работа
     без HTTP — это **процессорный** Python-код (`markdown-it`): GIL пускает к процессору только один поток за раз, поэтому
     2/5/10 воркеров делят одно ядро → 0.60/0.65/0.66 с, а не быстрее.
  3. Увеличивать число потоков **без HTTP бесполезно** (см. строку 1: 10 потоков = 0.66 с), **с HTTP — полезно**:
     воркеры ждут сеть, GIL в это время свободен → 5 потоков ×5.4, 10 потоков ×10.6. Значит, `speedup` — метрика
     сетевого режима; в ДЗ по умолчанию `http.enabled=false` — потому и 0.92. Предложение: в README метрики
     параллельности показать **оба** режима (H-07 так и делает — локальный сервер с задержкой, воспроизводимо).
  4. Планка «без HTTP ≥ 0.95» = «5 потоков не должны быть заметно хуже 1» — единственное честное требование под GIL;
     чтобы разбор ускорялся потоками, нужен либо `ProcessPoolExecutor` (ломает правило владения), либо free-threaded
     сборка Python 3.14 (`python3.14t`, без GIL) — можно попробовать отдельным экспериментом, если интересно.
