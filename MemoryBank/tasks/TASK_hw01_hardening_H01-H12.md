### 0.4 Среда (🔧 р6 — чтобы не спотыкаться на том, на чём спотыкались агенты этапа 1)

- Корень репо; `python` = `.venv` (Windows: `.venv/Scripts/python`, Debian: `.venv/bin/python`); команда тестов —
  `python -m pytest tests/hw01 -q`. Python дома 3.14, на Debian 3.12; абсолютные Windows-пути в **коде и документах**
  запрещены (в командах ручных прогонов на этой машине — допустимо).
- `gh` **не в PATH Git-Bash**: перед прогонами `export PATH="$PATH:$HOME/.local/gh/bin"` (PowerShell: уже в PATH).
  `SourceFactory` зовёт `gh` из PATH — без этого `discovery: auto` уйдёт в REST без токена.
- Деревья в `out/` игнорируются git → при сканировании `out/…` нужен `-scan.respect_gitignore:false`.
- Цель-подкаталог репозитория сканируется в границах подкаталога (`RepoInfo.scope`), `root` — git-корень.
- Учёт токенов: агент ничего не считает; ярлык `TASK=H-XX` первой строкой промпта — единственное, что нужно.
- Python 3.14: у `threading.Thread` заняты имена `_context`, `_args`, `_target`, `_name`… — в наследниках не использовать.
- Агент может упасть на лимите сессии — оркестрант перезапустит с тем же промптом; **не оставляй полуфайлов**
  без пометки в отчёте.
