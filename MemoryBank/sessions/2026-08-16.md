# Сессия 2026-08-16 — развёртывание каркаса репозитория

## Что сделано

Развёрнута полная инфраструктура проекта под домашние задания курса по ИИ
(перенос конфига из `Test_3FFT_model`/radar3d + адаптация под учебный репозиторий).

- **`.claude/`**: `settings.json` (permissions + 3 хука), `hooks/` (pre_bash — блок опасных
  команд и pytest; post_write — напоминания по ДЗ/core; on_stop — MemoryBank),
  `rules/` — 9 правил, `skills/` — `delegate-sonnet`, `new-homework`.
- **`.mcp.json`**: filesystem / git / sequential-thinking / memory (пути относительные — Win+Debian).
- **MemoryBank**: `MASTER_INDEX.md`, `tasks/IN_PROGRESS.md`, `specs/`, `sessions/`, `changelog/`.
- **Код**: `common/` (TestRunner, set_seed, Stopwatch), `core/` (config/data/metrics/models/viz),
  `homework/` (контракт `HomeworkTask` + реестр + образец `hw01_intro`), `run_hw.py` (CLI).
- **Тесты**: 5 наборов `TestRunner` + агрегатор `tests/all_test.py`.
- **Прочее**: `pyproject.toml` (ruff/mypy, extras ml/nb/dl/dev), `README.md`, `data/README.md`,
  `Doc/templates/` (шаблон README ДЗ и TASK), `.gitignore` дополнен проектной секцией.

## Ключевые решения

- Базовый каркас — **без внешних зависимостей**: `run_hw.py hw01` работает на голом Python 3.11+,
  numpy/pandas/torch приезжают extras'ами по мере надобности ДЗ.
- Одно ДЗ = один пакет `homework/hwNN_<topic>/` + регистрация в реестре (не скрипты в корне).
- Вся математика и метрики — в `core/`, ДЗ = тонкая оркестровка (правило 07, прецедент radar3d).
- Артефакты в `out/hwNN/`, датасеты в `data/` — оба каталога вне git.

## Проверки

- `python run_hw.py --list` / `hw01` — отрабатывает.
- `python tests/all_test.py` — все наборы зелёные.
