# 06 — Структура одного домашнего задания

> **paths:** `homework/**`, `run_hw.py`
> Главное правило репозитория: **каждое ДЗ — отдельный пакет, запускаемый одной командой.**

## 🎯 Канон

```
homework/
  hw00_intro/        # образец каркаса (не ДЗ курса); задания курса — с hw01
    __init__.py        # реэкспорт класса задания
    README.md          # УСЛОВИЕ (что задано) + что сделано + метрики + выводы
    task.py            # класс HwNN...(HomeworkTask) — тонкая оркестровка
    solution.py        # (опц.) логика, специфичная ТОЛЬКО для этого ДЗ
  hw02_.../
```

- Имя пакета: `hwNN_<topic>` — номер двузначный, тема строчными ASCII (`hw03_linreg`).
- Класс задания: `Hw03LinReg(HomeworkTask)`, `hw_id = "hw03"`.
- Регистрация в реестре `homework/registry.py` → появляется в `python run_hw.py --list`.

## 🧩 Контракт `HomeworkTask` (Template Method)

```python
class HomeworkTask(ABC):
    hw_id: str            # "hw01"
    title: str            # "Введение: базовый пайплайн"

    def run(self, ctx: HomeworkContext) -> HomeworkReport:   # шаблон: setup → solve → report
        ...
    @abstractmethod
    def solve(self, ctx: HomeworkContext) -> dict[str, float]:
        """Вернуть метрики: {"accuracy": 0.93, ...}"""
```

- `ctx.out_dir` — куда писать артефакты (создаётся сам, лежит в `out/hwNN/`, git не трекает).
- `ctx.data_dir` — где искать датасеты (`data/`, git не трекает).
- `ctx.seed` — общий сид, зафиксирован (см. `08-ml-experiments.md`).
- `solve` возвращает **метрики**, печать — дело `run_hw.py` (SRP).

## ✅ Что писать в ДЗ, а что в `core/`

| Код | Где |
|-----|-----|
| Метрика (accuracy, F1, MSE) | `core/metrics/` — переиспользуется всеми ДЗ |
| Загрузка/сплит датасета | `core/data/` |
| Модель, которая нужна ≥2 ДЗ | `core/models/` |
| График общего вида | `core/viz/` |
| Специфика конкретного ДЗ | `homework/hwNN_*/solution.py` |
| Оркестровка «загрузил → обучил → посчитал → нарисовал» | `homework/hwNN_*/task.py` |

**Дубликат метрики/загрузчика в двух ДЗ = ошибка.** Второе использование → выносим в `core/`.

## 📄 README ДЗ — обязательные разделы

1. **Условие** (как задано на курсе, дословно/близко).
2. **Что сделано** — коротко, по пунктам.
3. **Как запустить** — `python run_hw.py hwNN`.
4. **Метрики / результат** — числа, не «работает».
5. **Выводы** — 2–5 строк своими словами (это учёба).

## 🚫 Чего не делать

- ❌ Скрипты в корне репозитория под каждое ДЗ (`hw1.py`, `hw1_v2.py`) — только пакеты.
- ❌ Копипаста прошлого ДЗ целиком «чтобы не сломать» — реюз через `core/`.
- ❌ Артефакты (PNG/CSV/веса) в git — они в `out/`, каталог игнорится.
- ❌ Менять условие ДЗ под удобство кода.
