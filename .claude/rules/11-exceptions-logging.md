## Перехват: ни одно исключение не уходит «в никуда»

| Уровень | Что делаем |
|---|---|
| Внутри worker'а (обработка одной единицы работы: файл, задача) | `except Exception as exc` → лог `ERROR` с трейсом (`logger.exception`) → **публикуем результат с ошибкой** (поле `error`) → поток продолжает работу |
| Внутри потока-обхода (репозиторий, каталог, источник данных) | так же: единица помечается ошибочной, остальные обрабатываются |
| Внутри потребителя (Observer / Reporter / писатель отчёта) | лог `ERROR`, переход к следующему элементу; тело потребителя целиком под защитой — его падение = потеря отчёта |
| Главный поток | один `except` вокруг всего прогона → лог `CRITICAL` + понятное сообщение человеку + код возврата `3` |
| **Никогда** | «голый» `except:` и `except Exception: pass` — запрещены (правило 05) |

## Логирование: каждый шаг конвейера, а не только ошибки

| Событие | Уровень |
|---|---|
| Старт: конфиг, вход, число потоков, включённые проверки (шапка лога) | `INFO` |
| Найдена крупная единица (репозиторий, датасет, модель) | `INFO` |
| Единица поставлена в очередь / взята потоком / дубль отсечён | `DEBUG` |
| Единица обработана (сколько, за сколько мс) | `INFO` |
| Каждый мелкий элемент — успех | `DEBUG` |
| Каждый мелкий элемент — проблема (битая ссылка, пропущенный файл) | `WARNING` |
| Ошибка чтения / разбора / внешнего вызова | `ERROR` с типом исключения и трейсом |
| Итоги прогона — теми же числами, что в отчёте | `INFO` |

- **Уровень по умолчанию `INFO`**, `DEBUG` включается ключом/полем конфига — иначе на 10 000
  единиц лог становится гигабайтным.
- Логгер **включён по умолчанию**, есть явный выключатель (`logging.enabled: false`).
- В многопоточном коде — `QueueHandler` + `QueueListener` (worker не блокируется на диске,
  строки не перемешиваются); `listener.stop()` — в `finally`, иначе теряются последние строки.
- Формат строки: `время | уровень | поток | контекст (repo/file/…) | сообщение`. Потоки — **с именами**
  по стадиям (`discover-1`, `parse-2`, `collector`), имя идёт в лог.
- `print()` — только в слое вывода; в остальном коде — логгер (правило 09 п.8).

## Тест-гейт

- Тест «ошибка одной единицы не роняет прогон»: битый файл/элемент → результат с `error`,
  остальные обработаны, код возврата не `3`.
- Тест «из N потоков N записей → в файле ровно N строк, ни одной битой».
