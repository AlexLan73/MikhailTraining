# data/ — датасеты

Каталог **не трекается git'ом** (кроме этого README): датасеты качаются локально.

## Правила

- Файлы кладём прямо сюда: `data/<name>.csv` — код обращается через
  `ctx.data.require("<name>.csv", source="<ссылка>")`.
- Нет файла → ДЗ падает с понятным сообщением, где его взять; тест уходит в `pytest.skip(...)`.
- Мелкие игрушечные примеры (<100 КБ) можно закоммитить явно (`git add -f`).
- Крупные скачивания (>600 МБ) — только по явному «качай»: сначала полный список файлов
  и суммарный объём (см. `.claude/rules/08-ml-experiments.md`).
