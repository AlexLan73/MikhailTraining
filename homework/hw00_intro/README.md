# ДЗ 00 — Образец: сквозной прогон каркаса

> Это **не задание курса**, а вводный образец структуры (эталон для всех `hwNN`).
> Задания курса нумеруются с `hw01`.

## Условие

Проверить, что репозиторий собран правильно и одно задание запускается одной командой.
Заодно — эталон структуры для всех следующих ДЗ.

## Что сделано

- Игрушечный датасет: два гауссовых облака на прямой (класс 0 ≈ 0.0, класс 1 ≈ 2.0),
  400 объектов, генерация детерминирована сидом.
- Детерминированный сплит 75/25 (`core.data.train_test_split`).
- Две модели из `core.models`: `MajorityClassifier` (baseline) и `ThresholdClassifier`.
- Метрики из `core.metrics`: accuracy, F1.
- Артефакты: `out/hw00/metrics.json`, `out/hw00/predictions.json`.

## Как запустить

```bash
python run_hw.py hw00
```

## Выводы

- Baseline (самый частый класс) даёт 0.50 — классы сбалансированы, «угадать» нельзя.
- Одномерный порог ≈ 0.99 ≈ середина между центрами облаков (0.0 и 2.0) — то, что и должно
  получиться при равных дисперсиях; выше 0.91 не прыгнуть: при σ=1 и расстоянии 2σ облака
  перекрываются, теоретический предел точности ≈ Φ(1) ≈ 0.84…0.92 на выборке 100 объектов.
- Каркас работает сквозняком: сид → данные → модель → метрики → артефакты в `out/`.
